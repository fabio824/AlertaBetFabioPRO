# 🚨 Alerta Bet Fábio PRO

Bot para Telegram que monitora jogos ao vivo e envia alertas de oportunidades para:

- 🚩 Escanteios
- ⚽ Gols

## Método Fábio

### 1º Tempo
- 25 a 40 minutos

### 2º Tempo
- 70 a 85 minutos

## Critérios

- Favorito empatando ou perdendo
- Ataques perigosos
- Finalizações
- Escanteios
- Pressão ofensiva

## Objetivo

Enviar apenas oportunidades de alta qualidade para o Telegram.
